Lumen

With Lumen, the web client plays files as they are: the browser remuxes them and decodes the audio itself, and the server only sends bytes. A file Lumen cannot play is played as before, by the regular player.

When disabled, the web client page is served without the Lumen script: nothing is played by Lumen and nothing is logged. Takes effect the next time the page is loaded.
When unchecked, the script stays in the page but lets the regular player do the playing. This is the switch to flip for a comparison: playbacks are then logged "without Lumen", measured the same way.
When unchecked, Lumen only plays for the users selected below.
Every playback in the web client is recorded on the server: user, title, player, and what the viewer waited for (first frame, seeks, stalls). The log stays on this server and is shown below.

Playback log

Times run from the playback request to the first frame shown. Medians only compare like with like: the same file played with and without Lumen. "ffmpeg" is the CPU time the server spent transcoding, remuxing and extracting subtitles for that file during the playback (Linux only).
